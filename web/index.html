Cada tema tem variante clara e escura. O modo Sistema segue o que o teu computador disser, e muda sozinho se o ligares com a página aberta. O QR code fica sempre preto sobre branco: um código tem de ser legível, e a impressão não perdoa.

A norma do QR pede 4. Só mexa se souber o que está a fazer.

Apaga os módulos do meio para lá pôr um logótipo. O conteúdo continua a ler-se: é a correcção de erros que reconstrói o que foi apagado.

Sem ficheiro, fica só o quadrado apagado — que é o que o FieldQR está feito para: os dados dentro dele são reconstruídos pela correcção de erros.
