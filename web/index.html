Modo

Cada tema tem variante clara e escura. O modo Sistema segue o que o teu computador disser, e muda sozinho se o ligares com a página aberta. O QR code fica sempre preto sobre branco: um código tem de ser legível, e a impressão não perdoa.

A norma do QR pede 4. Só mexa se souber o que está a fazer.

Apaga os módulos do meio para lá pôr um logótipo. O conteúdo continua a ler-se: é a correcção de erros que reconstrói o que foi apagado.

A forma decide quantos módulos se apagam, e isso decide se o código se lê. O quadrado é o que apaga mais; o círculo e a estrela apagam menos com o mesmo logótipo, e por isso o limite é maior neles.

Sem ficheiro, fica só a área apagada — que é o que o FieldQR está feito para: os dados dentro dela são reconstruídos pela correcção de erros.

A chave é tua e só tua. Sem a chave, este conteúdo está perdido para sempre — não há recuperação e não há segunda tentativa. A chave não é guardada em lado nenhum: nem no servidor, nem neste dispositivo, nem no histórico do browser. Sai do campo abaixo quando sais desta página, e é por isso.

Qualquer texto serve. A mesma chave tem de ler o código — uma diferença de um carácter, e o código não abre.

Para ter vários SQRC com chaves diferentes no mesmo sítio, e saber de que chave é cada um sem abrir nenhum. Os bytes deste campo vão no código, e quem o ler vê-os — não é segredo.
